# Amazon Review Sentiment Analysis

## Project Overview
This project performs sentiment analysis on Amazon product reviews using RoBERTa.

## Dataset
Amazon Reviews Dataset

## Technologies Used
- Python
- Pandas
- NLTK
- Transformers
- PyTorch

## Model
- RoBERTa (cardiffnlp/twitter-roberta-base-sentiment)

## Results
The model predicts Positive, Negative, and Neutral sentiments.
